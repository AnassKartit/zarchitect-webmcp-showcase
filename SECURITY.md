# Security policy

## Scope

This repository contains only the standalone ZArchitect WebMCP showcase. It does not contain or accept reports about the private ZArchitect SaaS implementation, production infrastructure, credentials, customer data, or private projects.

The showcase is deliberately local-only: it has no application backend, authentication, file upload, remote MCP transport, or open-ended network tool.

## Reporting a vulnerability

Use this repository’s **Security** tab to report a vulnerability privately. Please do not publish exploit details, credentials, production URLs, private project identifiers, or customer information in a public issue.

Include the affected tool or page, the smallest reproducible input, the observed result, and the expected safety behavior. Reports about the public showcase will be evaluated against [the documented threat model](docs/THREAT-MODEL.md).

## Supported version

Only the current `main` branch and the currently linked public demo are supported.
